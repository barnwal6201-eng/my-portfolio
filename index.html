Full-stack · MERN · Payments

CineVerse Movie ticket booking

A booking platform with two apps: a customer site for browsing movies, trailers, cast and showtimes, and a separate admin panel for running the catalogue.

  • Interactive seat map with standard and recliner pricing, cutting time to book by roughly 50%.
  • Stripe checkout so users pay for selected seats and confirm the booking in one flow.
  • REST API in Express and Mongoose; poster and cast uploads via Multer to Cloudinary.
  • Admin panel for movies, posters, showtimes and seat pricing, reducing content effort by about 45%.

How I built itThe browser only sends seat IDs. The server works out each seat's price from its row (recliner rows cost more), totals it in paise, and only then creates the Stripe payment, so the amount charged comes from the server, not the page.

Try checkout with Stripe's test card 4242 4242 4242 4242, any future date and any CVC. No real money is charged.

Hirrd Job portal

Recruiters post openings and candidates search and apply, each with their own experience.

  • Role-based access with Clerk keeps recruiter and candidate flows cleanly separated.
  • Supabase stores jobs and applications; deployed on Vercel.
  • Mobile-first UI with Tailwind and Lucide icons, speeding up job posting by around 50%.

How I built itOn first sign-in, users pick Recruiter or Candidate. The choice is saved on their Clerk profile, and a protected route sends signed-out visitors to sign-in and anyone without a role to onboarding. Each role then lands on its own home: posting jobs or browsing them.

Try it: sign up with any email, then choose Recruiter to post a job or Candidate to search and apply.
